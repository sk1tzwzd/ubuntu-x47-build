# X47-Win lives in its own repo

The Windows 11 privacy kit is no longer part of Ubuntu X47.

- Site: https://sk1tzwzd.github.io/X47-Win/
- Source: https://github.com/sk1tzwzd/X47-Win

Stage onto a mounted Windows volume with `./scripts/stage-x47-windows.sh` (clones X47-Win). Encryption is optional on X47-Win (BitLocker or VeraCrypt). If you used BitLocker, import the USB key here with `x47-windows-import-key`.
