X47 Windows

Windows 11 as an X47 privacy twin

Same circuit wallpaper, less junk, less telemetry, BitLocker with a PIN that does not break Ubuntu.

Do this once, in Windows, as Administrator
  1. Stay on AC power. Plug in a USB stick.
  2. Right-click C:\X47\Install-X47Windows.bat → Run as administrator.
  3. Type YES.
  4. Set a 6+ digit BitLocker PIN when asked. Photograph the 48-digit recovery key.
  5. Wait until manage-bde -status C: says 100% and Protection On.
  6. Shut down Windows fully. Boot Ubuntu. Import the USB key (below).

Two passwords, on purpose

Ubuntu already asks for LUKS before Linux starts.

Windows will now ask for a BitLocker PIN after you pick Windows in GRUB / the firmware menu.

One secret will never unlock both. That is what “works when dual booting” means: each OS unlocks itself; GRUB is not encrypted.

After you return to Ubuntu

The USB copy is the one that matters. After encryption, Linux cannot read C:\X47 without the key.

x47-windows-import-key /media/$USER/<USB>/X47-BitLocker-Recovery-*.txt

That stores ~/.config/x47/bitlocker-recovery.txt (mode 0600) for X47 Ark / dislocker, then checks that Ubuntu is still the EFI default.

If Windows asks for the 48-digit key

An Ubuntu shim/GRUB update can change EFI PCRs. The PIN still works most of the time; if Windows falls back to the recovery key, type the 48 digits once.

Before a big Ubuntu bootloader update you can, from Windows:

manage-bde -protectors -disable C: (suspend) → update Ubuntu → boot Windows with PIN → manage-bde -protectors -enable C:

What we cannot remove

  • SMBIOS / board UUID — firmware.
  • MachineGuid — wiping it breaks activation, Update, and BitLocker.
  • TPM endorsement key — required for BitLocker.
  • Telemetry cannot go to “Security only” on Pro (Enterprise SKU only). Required is the floor.
