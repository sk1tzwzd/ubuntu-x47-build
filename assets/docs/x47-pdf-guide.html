X47 PDF

Edit PDFs without Adobe

One app — X47 PDF — asks what you want to do, then opens the right free tool. This page is the full walkthrough.

Start here
  1. Open the app grid and launch X47 PDF (red PDF tile).
  2. Or in Files: right-click a PDF → Open With → X47 PDF.
  3. Pick one of the four rows. That is the whole workflow.

Which row do I pick?

Edit text and images Opens ONLYOFFICE. Use this to change words, swap a logo, add a text box, or fill a typed form.
Merge, split, reorder, crop pages Opens PDF Arranger. Use this to combine contracts, drop a page, rotate a scan, or crop margins.
Highlight, sign, fill, scribble Opens Xournal++. Use this to mark up a document, draw a signature, or write on a scan.

1. Edit text and images — ONLYOFFICE

This is the closest free Linux app to “click the PDF and change the words.”

  1. From X47 PDF choose Edit text and images. If you already picked a file, it opens that PDF.
  2. If the start screen appears instead: Open file and choose your PDF. You can also drag the PDF onto the window.
  3. Click a line of text. Type the new words. Click outside the box when you are done.
  4. To add new text: toolbar → Insert → Text Box, then click the page.
  5. To replace a picture: click the image → Replace (or delete it and Insert → Image).
  6. Save: Ctrl+S. Prefer File → Save as the first time so you keep the original.
If the layout jumps

PDFs are not Word files. Fancy multi-column or designed pages can shift when you edit. If a paragraph will not reflow, add a text box on top of the old line, or use File → Download as → DOCX, edit that, then export a new PDF.

Forms and comments in ONLYOFFICE

  • Typed form fields: click the field and type. If the PDF is a flat scan with no fields, use a text box instead.
  • Comments / highlights: look for the Comment or review tools in the right sidebar.
  • You can also open Word / Excel / PowerPoint in the same app. Ignore that if you only care about PDFs.

2. Merge, split, reorder — PDF Arranger

Think of this as a light table of page thumbnails. It does not change the words on a page.

  1. From X47 PDF choose Merge, split, reorder, crop pages.
  2. Drag one or more PDFs into the window, or use + / Open.
  3. Reorder: drag a thumbnail left or right.
  4. Delete a page: select it → Delete.
  5. Rotate: select page(s) → rotate buttons in the toolbar.
  6. Merge: open several PDFs in the same window, order the thumbnails, export once.
  7. Split: select the pages you want, then Export (or save a selection) to a new file.
  8. Crop: select a page → crop tool → drag the box → apply. Export when it looks right.
  9. Always Export / Save as a new PDF. Do not overwrite the original until you have checked the result in Papers.

3. Highlight, sign, scribble — Xournal++

This draws on top of the PDF. The original text stays underneath. Perfect for signatures and markup.

  1. From X47 PDF choose Highlight, sign, fill, scribble.
  2. If you opened a blank notebook instead of your PDF: File → Annotate PDF and pick the file.
  3. Highlighter in the toolbar: drag over text.
  4. Pen: sign or circle something. Use a mouse, or a stylus if you have one.
  5. Text tool: click and type (good for short form answers on a scan).
  6. Eraser removes only your ink, not the original PDF.
  7. To reuse a signature: sign once, Edit → Select Object, copy, paste onto later pages. Or Insert → Image if you have a PNG of your signature.
  8. Export: File → Export as PDF. This flattens your marks into a normal PDF other people can open.
Do not stop at Save

File → Save writes a .xopp project. Other people cannot open that. When you are done, always Export as PDF.

Everyday recipes

I need to…Do this
Fix a typo on a digital PDF X47 PDF → Edit text → click the line → type → Save as
Combine three PDFs into one X47 PDF → Arrange pages → add all three → drag into order → Export
Remove one page from a pack Arrange pages → select the thumbnail → Delete → Export
Sign a form X47 PDF → Highlight / sign → Pen (or paste a signature image) → Export as PDF
Fill a scanned paper form Highlight / sign → Text tool for each blank → Export as PDF
Mark comments on a contract Highlight / sign → Highlighter + Text → Export as PDF
Replace a logo Edit text → click the image → Replace
Just read a PDF Double-click it. That still opens Papers (the viewer). X47 PDF is only for editing.

From the terminal

x47-pdf — chooser

x47-pdf edit ~/file.pdf — ONLYOFFICE

x47-pdf pages ~/a.pdf ~/b.pdf — PDF Arranger

x47-pdf mark ~/file.pdf — Xournal++

x47-pdf guide — this page

What this cannot do like Adobe Acrobat Pro

  • Heavy print-prepress (bleed, colour separations, preflight).
  • Guaranteed font-perfect edits on designed marketing PDFs — layout can shift.
  • Adobe-only DRM / some enterprise form features.
  • One-click OCR of a bad scan. For that, look at ocrmypdf later if you need it.

For almost every day-to-day PDF (typos, merges, signatures, markup), the three tools above are enough and they stay free.

If a tool is missing

Re-run the installer module from the X47 repo:

./install.sh --only 27-pdf

Or by hand:

sudo apt install pdfarranger xournalpp

sudo apt install onlyoffice-desktopeditors (after the official ONLYOFFICE repo is added)

X47 PDF is part of the Ubuntu X47 build. Viewing PDFs stays in Papers. Editing always goes through the X47 PDF chooser so you pick the right tool on purpose.
