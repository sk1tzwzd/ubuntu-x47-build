X47 on Windows

A privacy twin for the Ubuntu X47 machine: less junk, less telemetry, BitLocker with a pre-boot PIN that does not break GRUB, and an optional max-offline pass that blocks Microsoft account cloud.

Install on Windows Kit on GitHub

What this is

PowerShell scripts in windows/ that you run once, as Administrator, from Windows 11 Pro. Linux only copies the folder to C:\X47. It cannot enable BitLocker or change Windows from Ubuntu.

  • Same wallpaper option as Ubuntu X47 (circuit art)
  • Debloat — Xbox, Widgets, Copilot, OneDrive, consumer junk
  • Privacy — telemetry cut to Required, ads and location off
  • Security — inbound firewall, RDP off, Defender stays on
  • Anonymity — block Microsoft accounts and telemetry hosts
  • BitLocker + PIN — Windows unlocks itself; Ubuntu still uses LUKS
  • Looks — XP, remastered XP, Vista, Windows 10, or stock 11

Security — what we lock down

This is hardening, not “turn Defender off.” The goal is a smaller attack surface that still gets patches.

  • BitLocker (XTS-AES 256, full volume) with a TPM+PIN. Windows asks for your PIN after you pick it in GRUB. Ubuntu’s LUKS password is separate. TPM-only is avoided so an Ubuntu bootloader update is less likely to brick silent unlock.
  • Recovery key saved to USB (and imported on Ubuntu with x47-windows-import-key) so X47 Ark / dislocker can still read files from Linux.
  • Fast Startup off — required for clean dual-boot and so Linux can mount NTFS without a dirty hibernation lock.
  • Inbound firewall blocked on Private/Public. Outbound stays allow so Windows Update still works.
  • RDP, Remote Assistance, WinRM, Remote Registry disabled.
  • SMBv1, LLMNR, NetBIOS-over-TCP, WPAD, Teredo/6to4 off (less LAN discovery and fewer tunnel tricks).
  • AutoPlay / AutoRun off. UAC at the highest prompt. WDigest off; LSA protected process where the build allows.
  • Recall disabled. Defender and SmartScreen stay on — turning them off would be the opposite of security.

Privacy and anonymity — what we cut

Windows 11 Pro cannot go fully silent (Enterprise-only “Security” telemetry). This kit goes as far as Pro allows, then blocks extra cloud endpoints. That is the max-offline choice.

  • Telemetry = Required (lowest Pro allows). Feedback, tailored experiences, and CEIP tasks off. DiagTrack / dmwappush disabled.
  • Advertising ID off and rotated. SQM machine ID rotated. Device-metadata phone-home off.
  • Location, Find My Device, activity history, Timeline, cloud clipboard, Start web search, Cortana off.
  • Microsoft accounts blocked (local sign-in only). If the user is already an MSA, switch to a local account in Settings, then re-run the anonymity script.
  • Hosts + firewall block telemetry, Store, OneDrive, Xbox Live, and login.live.com. Windows Update and Defender definition hosts are not on that list.
  • OneDrive uninstalled (already-synced files stay on disk).
  • Wi-Fi MAC randomization on. NTP moved off time.windows.com to pool.ntp.org.
This is not a Tor amnesia session. The board UUID, TPM, and Windows MachineGuid stay — wiping them breaks activation and BitLocker. Your ISP still sees the PC’s IP unless Mullvad (or similar) is running on Windows. Store, OneDrive, Xbox Live, and “Sign in with Microsoft” will break. Revert hosts with Apply-X47Anonymity.ps1 -Revert.

Looks

Switch anytime with C:\X47\Apply-X47Theme.bat. Screenshots will land here once they are taken. These placeholders mark the six looks.

Looks change Start, taskbar, wallpaper, and accent. They do not patch uxtheme or ship Microsoft Luna/Aero files.
