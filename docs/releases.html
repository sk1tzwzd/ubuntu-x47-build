Releases

GitHub releases are kept slim on purpose: one Latest for the current installer scripts, and a small set of ISO archives when a bootable image was baked.

What to download

  • Latest (source) — releases/latest — current install.sh tree. Prefer this for updates on an existing Ubuntu machine (git pull or the release zip).
  • Installer ISO — look for a release titled Installer ISO (assets end in .iso.*.part). Rejoin parts before flashing — see Install.

Current versions

  • v1.12.0 — Latest (source) — Performance + Visual (dock off both), display comfort with sticky Night Light off, stock Firefox chrome, Syncthing helper, Nerovia widgets retired.
  • v1.9.2 — Installer ISO — flashable image (split parts). Source has moved on; use Latest for scripts on an existing install.
  • v1.6.0 — Installer ISO (archive) — older ISO bake, kept as pre-release.

Full notes live in CHANGELOG.md. Empty one-line tags were folded into that log and removed so the Releases list stays readable. 

# clone / update
git clone https://github.com/sk1tzwzd/ubuntu-x47-build.git
cd ubuntu-x47-build && git pull

# or grab Latest from GitHub, then:
chmod +x install.sh modules/*.sh
./install.sh                  # lean desktop + tooling
./install.sh --with-amnesia   # also provision anon
