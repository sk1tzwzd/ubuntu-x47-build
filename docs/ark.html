X47 Ark

Backup Windows user files to a USB stick, verify the copy, then give the disk to Ubuntu. Installed with the Ubuntu X47 build. Search Ark or open Show Apps → Utilities.

What it does

  • Scan — finds the Windows partition on a dual-boot disk
  • BitLocker unlock — paste the 48-digit recovery key; uses dislocker. Does not crack BitLocker
  • Copy — Documents, Desktop, Downloads, Pictures, Videos, Music to an external USB (not the dual-boot drive)
  • Verify — read-tests folders and compares sample SHA-256s
  • Reclaim — after verify, delete Windows and grow Ubuntu. Typical “Windows first” layouts write a live-USB finisher instead of moving a mounted root

How to run it

x47-ark              # GTK assistant (Zenity fallback)
x47-ark detect       # layout only
x47-ark backup /media/$USER/USB
x47-ark verify
x47-ark reclaim      # type DELETE WINDOWS after verify
x47-ark guide        # offline walkthrough

Skip at install time with ./install.sh --skip-ark.

Limits

The backup cannot live on the same disk you are about to wipe. Fast Startup / hibernate on Windows can lock NTFS — shut Windows down fully first. Reclaim is destructive; verify must pass. X47-Win (the Windows privacy kit) does not delete the Windows partition — that is Ark on Ubuntu.
